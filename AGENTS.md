# Agent Operating Rules

## Mission
Work on the project in small, verifiable steps.
Prioritize correctness, clarity and useful results.

## Before starting
1. Understand the task.
2. Inspect the relevant files.
3. Check existing tasks and project context.
4. Make a short plan before changing code.

## While working
1. Make the smallest useful change.
2. Do not modify unrelated files.
3. Prefer simple solutions over unnecessary complexity.
4. Keep track of decisions and important findings.
5. If something is unclear, investigate before guessing.

## Validation
After making changes:
1. Run relevant tests or checks.
2. Inspect the result.
3. Fix obvious problems.
4. Report what changed and what remains open.

## Communication
When reporting progress:
- State what was done.
- State what was found.
- State what is blocked.
- Suggest the next concrete step.

Never claim something works without checking it.
